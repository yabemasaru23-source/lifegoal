# ライフゴール｜夢をかなえる手帳

やりたいことを6分野に書き出し、日付をつけ、絵をつける。
最後に、自分が書いた言葉の中から人生の目的・座右の銘・辞世の句が現れます。

- 公開URL: https://yabemasaru23-source.github.io/lifegoal/
- HTML1ファイルで完結（外部依存はGoogle Fontsのみ）
- データは利用者のブラウザ内だけに保存されます。サーバーには何も送られません

## できること

- 4ステップ（書き出す・日付をつける・絵をつける・終わりから）＋はじめにのプロフィール
- 写真または絵文字で夢に絵をつける
- 手帳ページ：ピラミッド／年表ロードマップ／6分野の一覧／夢の地図／遺したいもの
- 出力（A4）：宝地図（縦）・人生ロードマップ（横）・今年のチェックシート（縦）。画像保存と印刷
- 使い方ガイド、各ステップのコツ
- バックアップ：JSONファイルで保存・読み込み（テキストでのコピーも可）

旧版（保存キー `yume-techo-v4` 以前）のデータはそのまま引き継がれます。

## 出典

6分野と3レベルの名称は熊谷正寿氏の夢手帳の構成に、宝地図の考え方は望月俊孝氏に、
「終わりから考える」問いは『7つの習慣』第2の習慣に拠っています。
各書籍・商品とは無関係の非公式ツールです。
